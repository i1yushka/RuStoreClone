# RuStoreClone

Учебное клиентское Android-приложение — каталог мобильных приложений, реализованный как аналог витрины RuStore. Проект выполнен в рамках учебной ознакомительной практики.

## Функциональность

Приложение реализует полный обязательный набор экранов и функций из задания:

- **Онбординг** — показывается только при первом запуске, содержит логотип, приветственный текст и кнопку перехода к витрине
- **Витрина приложений** — список приложений с иконкой, названием, кратким описанием и категорией; переход в карточку приложения и к списку категорий
- **Список категорий** — отображение категорий с количеством приложений в каждой; клик открывает витрину, отфильтрованную по категории
- **Поиск** — интерактивный поиск приложений по названию с автоматическим открытием клавиатуры
- **Карточка приложения** — иконка, название, разработчик, категория, возрастной рейтинг, горизонтальный список скриншотов, полное описание, кнопка «Установить»
- **Просмотрщик скриншотов** — полноэкранный просмотр с горизонтальной прокруткой, открывается по клику на скриншот в карточке

Дополнительно на всех экранах реализованы:
- Обработка ошибок и устойчивость к сбоям (состояния Loading / Success / Error)
- Обновление контента по свайпу (Pull-to-Refresh)

## Технологии

- **Kotlin** — язык программирования
- **Jetpack Compose** — декларативный UI-фреймворк
- **Navigation Compose** — навигация между экранами
- **ViewModel** (Android Architecture Components) — хранение и управление состоянием экранов
- **Material 3** — компоненты дизайна

## Архитектура

Проект построен по слоистому принципу с разделением ответственности:

```
com.example.rustoreclone
├── data
│   ├── model         — модели данных (App, Category, AgeRating)
│   └── repository    — источник данных приложения (AppRepository)
├── navigation         — граф навигации (Screen, AppNavHost)
├── ui
│   ├── onboarding     — экран онбординга
│   ├── catalog        — витрина приложений
│   ├── categories     — экран категорий
│   ├── search         — экран поиска
│   ├── appdetail      — карточка приложения
│   └── screenshots    — просмотрщик скриншотов
└── MainActivity.kt
```

Каждый экран состоит из ViewModel (управление состоянием и данными) и Composable-функции (отображение). Такой подход позволяет в дальнейшем безболезненно заменить источник данных — например, подключить реальный backend через Retrofit вместо локального `AppRepository` — без изменения кода экранов.

На текущем этапе данные приложения — это фиксированный тестовый набор из 5 демонстрационных приложений разных категорий, хранящийся локально в `AppRepository`.

## Сборка и запуск

### Требования

- Android Studio (последняя стабильная версия)
- JDK 17 (либо встроенный JDK, поставляемый с Android Studio)
- Android SDK с установленной платформой API 26+

### Шаги

1. Склонируйте репозиторий:
   ```
   git clone https://github.com/i1yushka/RuStoreClone.git
   ```
2. Откройте папку проекта в Android Studio
3. Дождитесь завершения синхронизации Gradle
4. Запустите приложение на эмуляторе или физическом устройстве (Android 8.0+) кнопкой **Run**
